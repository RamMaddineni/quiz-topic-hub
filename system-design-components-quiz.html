Select from the pressure

Questions 1–6 · identify the mechanism that attacks the measured constraint

1. Six identical stateless application servers are running. One receives 70% of requests and has a long queue; the other five sit near 20% CPU. What is the most direct correction?

The database is healthy, request work is similar, and the slow requests correlate with the overloaded application node.

2. A product-details query performs the same expensive join thousands of times per minute. Products change roughly every ten minutes, and the business accepts prices being at most 20 seconds old. What is the strongest first design?

3. A single 8 TB events database is approaching both its storage and sustained write ceiling. Almost every query is scoped to one account_id. Which mechanism most directly raises the ceiling?

4. A database still fits comfortably on one node and write capacity is fine, but read QPS is high and losing that one node would cause an unacceptable outage. What is the best fit?

5. Thumbnail generation takes 4–20 seconds and upload traffic arrives in bursts. The upload API should acknowledge durable intake quickly, while users can see “processing.” Which design matches that contract?

6. Finance needs a ranking over the previous day’s 400 million events by 6:00 AM. Nobody needs intermediate results, and compute is cheapest overnight. Which execution model is most appropriate?

Mechanisms and limits

Questions 7–13 · distinguish the benefit from the guarantee people wrongly assume

7. A load balancer already distributes traffic evenly, but every backend remains above 95% CPU for ten minutes and queues keep growing. What conclusion is justified?

8. A cache-aside service reads price ₹1,000 into cache. The database is then updated to ₹900, but no cache action occurs. What is the correct interpretation?

9. Which statement correctly separates partitioning from replication?

10. An eight-shard database stores each shard on exactly one machine. Machine 3 fails. What availability does partitioning alone provide?

11. A user updates their profile on the primary, immediately reads from a lagging replica, and sees the old name. Which response addresses the actual mechanism?

12. A worker charges a card, then crashes before acknowledging the queue message. The queue redelivers it. What must prevent a second charge?

13. Why can grouping 10,000 records into a batch improve throughput while making an individual record slower?

Production failure and synthesis

Questions 14–20 · debug hot spots, retry behavior, and composed architectures

14. Events are partitioned by country. Eighty percent of traffic belongs to India, so one shard is saturated while the rest are idle. What should the redesign optimize?

15. A money transfer debits an account on shard A and credits one on shard B. The invariant requires both changes or neither. What is the honest design statement?

16. A very hot cache key expires at noon. Thousands of requests miss simultaneously and all recompute the same database query, overloading the source. Which mitigation targets this failure?

17. Ten application replicas exist, but one load-balancer process is deployed on one machine. Its health check only proves the app process has a PID, not that it can serve traffic. What is the strongest correction?

18. The API still enqueues jobs in 30 ms, but queue age has grown from 10 seconds to two hours because producers are faster than consumers. Which status report is accurate?

19. A marketplace has repeated catalog reads that may be 30 seconds stale, strict inventory writes, receipt emails that may lag, and analytics due the next morning. Which decomposition preserves those different contracts?

20. A page takes 800 ms. Tracing shows 520 ms in one unindexed database scan, 180 ms in application work, and 100 ms in network time. Only 2% of requests repeat, app CPU is 25%, and users are near the region. What should the candidate say first?
