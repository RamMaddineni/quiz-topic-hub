C# structural pattern

Decorator

Wrap one object to add behavior without changing its class.

1

Subclasses multiply

Every feature combination threatens another subclass.

2

Wrap the same contract

A decorator is an IDataSource and has an IDataSource.

3

The C# shape

interface IDataSource { void Write(byte[] data); } sealed class CompressionDecorator : IDataSource { private readonly IDataSource inner; public void Write(byte[] data) => inner.Write(Compress(data)); }

The wrapper adds work, then delegates through the same interface.

4

Follow one call

Each layer may act before or after delegating.

5

Order is behavior

Runtime composition avoids subclass explosion, but many layers make tracing harder.

Use Decorator for optional, stackable behavior on individual objects.

Remember

Same contract+Wrapped component+Added behavior
